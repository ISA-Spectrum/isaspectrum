📦 ISA Spectrum macOS 安装说明

安装前请确认：
  • 您的设备是MacOS操作系统
  • 您拥有此设备的管理员权限（否则无法执行以下步骤）

第一步：下载并打开 DMG 文件

双击下载好的 ISAS_app_Mac.dmg 文件，系统会自动挂载并打开安装窗口。

第二步：安装应用

将窗口内的 ISA Spectrum 图标，拖到「应用程序」文件夹里，完成安装。

第三步：首次打开（系统安全提示处理）

  1. 找到 ISA Spectrum
  2. 双击打开
  3. 此时会有禁止打开的提示，点击完成即可
  4. 进入系统设置
  5. 找到隐私与安全性
  6. 翻到最下方，点击仍要打开，输入密码即可打开

这是 macOS 对非 App Store 应用的通用安全限制，只需操作一次，之后双击即可正常打开。

退出与关闭

应用全屏运行时，按 Esc 键可退出全屏；按 Command + Q 可完全关闭应用。

如果遇到问题：
  • 打不开：请检查是否已按第三步操作，绕过安全限制。
  • 窗口问题：首次打开后，可通过菜单栏「视图」调整显示模式。
