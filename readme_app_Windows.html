ISA Spectrum 桌面客户端安装说明

✨ 客户端介绍

这是 ISA Spectrum 校墙 的 Windows 桌面客户端，将网站打包为独立应用，打开即可使用，无需再开浏览器。所有功能与网页版完全同步，留言、公告、通知都能正常使用。

安装前请确认：

  • 您有这台设备的管理员权限

✅ 推荐安装方式（大部分用户适用）

  1. 下载并解压客户端压缩包，确保所有文件都在同一个文件夹中。
  2. 找到文件 ISAS.msixbundle，双击该文件。
  3. 按照系统提示完成安装，等待几秒即可。
  4. 安装完成后，在「开始菜单」中找到 ISAS，打开即可使用。

⚠️ 安装报错时的备用方案

如果遇到「无法验证发布者证书」或脚本运行报错，请按以下步骤操作：

  1. 解压压缩包后，在文件夹空白处按住 Shift 键，然后右键，选择「在此处打开 PowerShell 窗口（管理员）」。
  2. 在弹出的窗口中输入以下命令，按回车执行：
    Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
  3. 系统会提示确认，输入 A（全是）并按回车。
  4. 继续输入以下命令，按回车执行安装脚本：
    .\install.ps1
  5. 按照脚本提示完成安装即可。

💡 使用小贴士

  • 内容更新：客户端打开时会自动加载最新内容，若未更新，可在应用内按 Ctrl+Shift+R 强制刷新。
  • 同步功能：留言、公告、通知等所有功能与网页版完全同步，无需额外登录或设置。
  • 卸载方法：在 Windows「设置 → 应用」中找到 ISAS，点击卸载即可。
